# Block Deltas

The Aestus relay supports block delta submissions via *dehydrated blocks* compatible with the [Titan Relay spec](https://docs.titanrelay.xyz/builders/builder-integration#block-deltas).

This is a new feature for Aestus; if you would like to make use of it please get in touch and pardon some temporary hiccups.
